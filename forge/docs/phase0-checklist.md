# 実機確認の手順(AviUtl2 2.1.16)

Forge の生成物は、まだ AviUtl2 の上で一度も動かしていない。
ここが通れば「作ったエフェクトが標準エフェクトとして使える」ことが確定する。所要 10〜15 分。

## 準備

AviUtl2 を閉じた状態で、サンプル 5 本をスクリプトフォルダへコピーする
(コピー先は `C:\ProgramData\aviutl2\Script\Forge\`)。

```
bin\forge.exe install "out\色反転.anm2"
bin\forge.exe install "out\モザイク簡易.anm2"
bin\forge.exe install "out\2パスぼかし.anm2"
bin\forge.exe install "out\VHSノイズ.anm2"
bin\forge.exe install "out\ネオン輪郭.anm2"
```

やめたいときは `Script\Forge` フォルダを消せば元に戻る。

## 確認項目

| # | やること | 期待する結果 | 分かること |
|---|---|---|---|
| 1 | AviUtl2 を起動し、画像か動画のオブジェクトにフィルタ効果を追加する | メニューに「Forge」があり、5 本が並ぶ | 読み込み・`--label` |
| 2 | 「色反転」を追加 | 色が反転する。「強さ」を 0 にすると元に戻る | 定数バッファの並び、uv の向き |
| 3 | 透過 PNG に「色反転」 | 透明部分が透明のまま。縁に黒や白の線が出ない | 乗算済みアルファ |
| 4 | 「モザイク簡易」でサイズを変える | ブロックが正方形で、画像の上下左右がずれない | `pos` と `resolution` の対応 |
| 5 | 「2パスぼかし」 | 縦横に均等にぼける。画像サイズや位置が変わらない | `tempbuffer`、複数パス |
| 6 | 「VHSノイズ」を再生 | ノイズが時間で動く。色・チェック・リストが効く | `time`、`random`、色・チェック・選択項目 |
| 7 | 同じオブジェクトを複製して「VHSノイズ」 | 2 つのノイズ模様が違う | `seed` |
| 8 | 「ネオン輪郭」で値をキーフレーム移動 | 値が滑らかに変わる | トラックバーの移動 |
| 9 | フィルタオブジェクトとして「色反転」を置く | 下のレイヤー全体に効く | `--filter` |
| 10 | `bin\forge.exe render` の出力と、AviUtl2 の表示を見比べる | 見た目がほぼ同じ | ハーネスの再現度 |
| 11 | わざと壊した `.anm2`(HLSL の `;` を1つ消す)を置いて起動 | 落ちずにエラー表示か無効化 | エラー時の挙動(P0-7) |

## うまくいかなかったとき

- ログは `C:\ProgramData\aviutl2\Log\` に出る。エラー文をそのまま控える。
- 「メニューに出ない」→ ファイルの置き場とヘッダ行が原因。
- 「真っ黒・真っ白」→ 定数の並びか、サンプラ・バッファ名が原因。
- 「位置がずれる・サイズが変わる」→ `tempbuffer` の初期化か `--filter` が原因。

結果(番号と起きたこと)を伝えてもらえれば、生成テンプレートを直す。
直す場所は `crates/forge-core/src/emit.rs` と、対になる `verify.rs` の2か所だけ。
